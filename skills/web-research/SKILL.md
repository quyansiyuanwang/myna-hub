---
name: 联网调研
description: 对指定主题做联网调研，输出带来源链接的结论
tags: research, web
---
目标：围绕用户给定的主题做一次联网调研，给出结论与来源。

1. 先明确调研问题与范围；若用户描述含糊，用一句话复述你的理解再开始。
2. 调用 `web_search` 检索关键词，至少覆盖 2–3 组不同角度的关键词（例如「主题 + 现状」「主题 + 对比」「主题 + 风险」）。
3. 对最有价值的 2–3 条结果调用 `fetch_url` 抓取正文，提取关键事实、数字与结论。
4. 交叉核对：同一事实若只有单一来源，标注「单一来源」；相互矛盾时并列说明。
5. 输出结构：
   - 一句话结论
   - 关键发现（3–5 条，每条附来源链接）
   - 存在的分歧或不确定之处
   - 参考来源列表
6. 不要编造链接或数据；抓取失败时如实说明并改用搜索摘要。
7. 若未配置搜索服务商，提示用户在「设置 → 工具 → 网络搜索」中配置。
