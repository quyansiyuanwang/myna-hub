# 调研工具包（research-pack）

联网调研与网页总结的组合，**不需要任何外部运行时**：搜索与抓取都用 Myna 内建能力。

## 组成

- 技能 `web-research`：把一个问题拆成若干检索式，交叉核对多个来源后给结论。
- 技能 `summarize-url`：读取一个链接并按要点总结。

两个技能都只依赖内建工具（`web_search`、`fetch_url`），因此没有 MCP 依赖，也不需要
Node.js 或 uv。

## 使用

说「查一下 X 现在的情况」或「总结这个链接：https://…」。助手会先搜再抓，回答里带上来源。

## 依赖

联网搜索需要先在「设置 → 工具 → 联网搜索」填入搜索服务的 key（Tavily / Brave / Serper
或自定义端点），否则 `web_search` 不可用；`fetch_url` 不需要配置。

## 为什么不做成 MCP 插件

MCP 服务器必然是独立进程，需要外部运行时。这套流程用内建工具就能完成，做成 MCP 反而
增加了安装成本，因此保持为零依赖。
