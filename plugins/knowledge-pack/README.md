# 知识管理包（knowledge-pack）

把一周的日程、提醒与笔记收成一份可回看的周回顾，并把结论沉淀进长期记忆。

## 组成

- 技能 `weekly-review`：汇总本周日程与未完成事项，输出结构化周回顾。
- MCP `memory`：知识图谱记忆，跨周保留要点与关系。
- MCP `sqlite`：把结构化记录落到本地库，便于后续查询。

## 使用

说「做一下本周回顾」，助手会读取日历与提醒事项，然后写入记忆图谱与 SQLite。之后可以
问「上上周讨论了什么」这类跨周问题。

## 依赖

两个 MCP 都需要 Node.js（`npx`）。不需要持久化时，只启用 `memory` 也能跑；Myna 内建的
`read_file` / `write_file` 可以用来保存纯文本笔记。

## 存储位置

`sqlite` 的数据库路径由安装后填写的 `args` 决定，建议放在 `~/Documents` 之类可备份的位置，
不要放进 `~/.config/myna`（升级时会被覆盖管理）。
